# Introduction

Welcome to the Payflow Documentation.

Payflow is an online payment gateway that enables businesses to accept, process, and manage payments through secure REST APIs. Developers can use Payflow APIs to add payment functionality to websites, mobile applications, and other digital platforms.

This documentation helps developers understand the Payflow platform, integrate its APIs, manage payment transactions, and handle payment-related events.

## Who Should Use This Documentation?

This documentation is intended for:

- **Software Developers:** Developers integrating Payflow APIs into web or mobile applications.
- **Technical Architects:** Professionals designing payment integration workflows and system architectures.
- **Integration Engineers:** Engineers responsible for connecting business applications with payment services.
- **QA Engineers:** Professionals testing payment workflows and validating API responses.

## What Does This Documentation Cover?

The Payflow documentation is organized into the following sections:

## Prerequisites

Before exploring the proposed Payflow API examples, you should have:

- Basic knowledge of REST APIs and HTTP methods.
- Familiarity with JSON data formats.
- Understanding of HTTP status codes and request-response communication.
- Access to an API testing tool such as Postman.

Payflow is a fictional payment gateway created for a documentation capstone. It does not provide a live developer account or working API credentials.

## How to Use This Documentation

We recommend following these steps:

1. Read the [Overview](./overview.md) to understand the Payflow platform and its capabilities.
2. Review [Getting Started](../getting-started/prerequisites.md) to understand the setup requirements.
3. Explore the [API Reference](../api-reference/create-order.md) to learn about the proposed endpoints.
4. Follow the [Payment Integration Workflow](../guides/payment-integration-workflow.md) to understand the payment process.
5. Refer to [Handling Payment Errors](../guides/handling-payment-errors.md) when reviewing common API errors.
6. Read [Understanding Payment Statuses](../guides/understanding-payment-statuses.md) to learn about order, payment, and refund statuses.
